# Public Portfolio, Blog, and Learning Library

This document defines the terms for the public site's portfolio, blog, and technical courses. It keeps blog articles, courses, and lessons separate, and distinguishes learner-facing references from records of content origin.

## Language

### Public publishing

**Portfolio project**:
A selected piece of work presented as evidence of capability or experience. A portfolio project is separate from a course and from a blog article.
_Avoid_: Project (when referring to a published portfolio item)

**Blog article**:
A long-form editorial publication intended for the blog. A blog article may relate to a learning topic, but it is not a lesson.
_Avoid_: Lesson, tutorial (when referring to the content type)

### Learning library

**Learning library**:
The public collection of technical courses. It is separate from the blog.
_Avoid_: Lessons (when referring to the whole collection), blog

**Course**:
An ordered set of lessons with a purpose, learning objectives, prerequisites, difficulty, and references.
_Avoid_: Course shell, learning path (when naming the domain object)

**Course landing page**:
The learner-facing overview of a course. It introduces the course's purpose, scope, outcomes, prerequisites, sequence, and references before the learner opens an individual lesson.
_Avoid_: Course shell

**Course sequence**:
The ordered progression of lesson entries within a course.
_Avoid_: Curriculum (when referring only to the ordered lesson list)

**Lesson entry**:
A course-sequence item that identifies and summarises one lesson, whether the lesson is planned or published.
_Avoid_: Lesson (when referring only to a roadmap item), lesson card

**Lesson**:
A learner-facing instructional unit within a course. It explains one bounded subject and can include examples, practice, pitfalls, and references.
_Avoid_: Lesson entry, blog article

**Planned lesson**:
A lesson entry whose learner-facing instructional content is not yet available.
_Avoid_: Draft lesson, unavailable lesson

**Published lesson**:
A lesson whose learner-facing instructional content is available as part of a course.
_Avoid_: Live lesson, available lesson

**Pilot**:
A limited first release of a course or learning experience, used to test the course format before publishing more material.
_Avoid_: Difficulty, lesson status, beta

**Course lifecycle**:
The release state of a course, such as pilot or published. It is distinct from the availability state of each lesson in the course.
_Avoid_: Lesson status

**Lesson availability**:
The state that describes whether an individual lesson is planned or published. It is distinct from the course lifecycle.
_Avoid_: Course status

### Learning design

**Difficulty**:
A broad classification of learner level: beginner, intermediate, or advanced. Difficulty indicates the expected level of the material; it does not replace prerequisites.
_Avoid_: Prerequisite

**Prerequisite**:
Knowledge or experience a learner should have before beginning a course or lesson.
_Avoid_: Difficulty

**Learning objective**:
A capability the learner should gain by completing a course or lesson. An objective describes an outcome, not only a subject.
_Avoid_: Topic, subject

**Topic**:
A subject label used to classify or help discover learning content. A topic does not state what the learner will be able to do.
_Avoid_: Learning objective, learning outcome

**Quiz**:
A short knowledge check that gives immediate correctness feedback, an explanation, and an opportunity to retry.
_Avoid_: Assessment (when referring to a short lesson knowledge check)

**Retrieval prompt**:
A prompt that asks the learner to recall or explain a concept before showing a model answer.
_Avoid_: Say-it-aloud prompt, quiz

**Demonstration**:
A runnable or inspectable example that shows how a concept works.
_Avoid_: Production example

**Offline-safe demonstration**:
A demonstration that can be understood or run without a backend or network connection.
_Avoid_: Mocked demo

**Network-dependent example**:
An example whose operation depends on an external service or network connection. It is distinct from an offline-safe demonstration and must be identified as such for learners.
_Avoid_: Offline demo

### References and origin

**Further reading**:
A set of external learning resources chosen for further study. Further reading is not a record of where the course or lesson originated.
_Avoid_: Source (without a qualifier), bibliography

**Source traceability record**:
A record of where public learning material came from. It is not a learner-facing reference.
_Avoid_: Source (without a qualifier), further reading, citation

**Authoring source**:
The original instructional material from which a public course or lesson is prepared. It is distinct from the external resources selected as further reading.
_Avoid_: Curated source

**Glossary**:
A learner-facing reference that defines the important terms for a course or lesson.
_Avoid_: Reference page

**Learning resource**:
An external item that supports further study, such as documentation, an article, or a book. Learning resources belong in further reading rather than in source traceability.
_Avoid_: Authoring source
